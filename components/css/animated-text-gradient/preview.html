Sand & Surf · saltycodestudio

Color that never stands still.

A single headline filled with a slowly drifting multi-stop gradient — clipped to the letterforms with background-clip: text. No JavaScript, no canvas, just a couple of @keyframes.

Hero titles

Living headlines

Drop the class on any heading. The gradient loops seamlessly because the last color stop repeats the first.

Tune per use

Faster drift

Every knob is a CSS custom property — angle, size, speed, and color stops — so each headline can feel different.

Sand variant

Warm gold

Swap the --sand modifier for a gold-into-ocean blend that suits accent or seasonal titles.

Reduce-motion friendly · the gradient holds still when a visitor prefers reduced motion.
