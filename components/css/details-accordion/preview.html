Frequently asked, smoothly answered.

A native, accessible accordion that animates open and closed from height 0 to auto — with exactly zero JavaScript.

01 How does it animate without JavaScript?

It transitions the native ::details-content box from height: 0 to height: auto, made possible by interpolate-size: allow-keywords and transition-behavior: allow-discrete. A grid-template-rows: 0fr → 1fr wrapper handles browsers that don't support the modern path yet.

02 Is it accessible out of the box?

Yes. <details> and <summary> are focusable, toggle on Enter or Space, and expose proper expanded/collapsed state to screen readers — no ARIA wiring required.

The chevron is marked aria-hidden since it's purely decorative.

03 Why does only one panel open at a time?

Every <details> in this group shares the same name="faq" attribute. The browser enforces exclusivity natively — opening one closes the others. Remove the name to allow several panels open at once.

04 Can I drop it straight into my site?

Absolutely. Copy styles.css and the markup from index.html, swap in your own content, and you're done. It respects prefers-reduced-motion and uses only the Sand & Surf tokens, so it themes cleanly with the rest of the kit.

Try it: clicking a header smoothly animates height. Older browsers fall back to the grid-template-rows path automatically.
