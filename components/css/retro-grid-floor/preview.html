Retro Synthwave grid floor

An infinitely scrolling Tron / vaporwave floor that recedes to a glowing horizon — drawn entirely from layered repeating-linear-gradients on a single perspective() rotateX() plane. No canvas, no JavaScript, no images. Just CSS marching one grid cell per loop.

drive into the gradient sunset · 1986 forever

How it works: two repeating-linear-gradients paint the rows and columns; the row layer's background-position-y animates by exactly one cell so the loop is seamless. The whole plane is tipped with perspective(14em) rotateX(58deg), and a mask-image fade dissolves the far lines into the horizon. Tune everything via CSS custom properties. Honors prefers-reduced-motion by freezing the scroll.
