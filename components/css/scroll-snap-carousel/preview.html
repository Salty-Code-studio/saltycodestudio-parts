A carousel with zero JavaScript

Prev/next buttons and dot pagination are generated entirely by the browser from ::scroll-button() and ::scroll-marker. Swipe, drag, click the arrows, tap a dot, or use the keyboard.

Heads up on support. The horizontal scroll-snap works in every modern browser today. The generated arrow buttons and dot markers rely on ::scroll-button() and ::scroll-marker (CSS Overflow Level 5). Where those aren't supported yet, the carousel gracefully degrades to a clean swipe / drag experience — nothing breaks, the extra controls simply don't render. Try it in a recent Chromium build to see the buttons and dots.
