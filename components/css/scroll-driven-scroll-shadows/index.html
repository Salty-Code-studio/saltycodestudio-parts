CSS Scroll Shadows

Add class="sds-scroller" to any element that scrolls vertically and give it a height or max-height. The shadows wire themselves up purely in CSS: they appear at whichever edge is hiding more content and vanish on containers that cannot scroll at all.

Long content that overflows the panel. Scroll and watch the edges.

The top shadow appears the moment a little content hides above you.

The bottom shadow is already there, hinting at what is still below.

Both fades ride the container's own scroll progress timeline.

No scroll listeners, no observers, no resize math anywhere.

Resize the window or edit the content, the shadows keep up on their own.

Keyboard scrolling, dragging and flinging all stay perfectly in sync.

The bottom shadow fades out right here, at the end.

Short content. No overflow, no shadows.

A stronger, taller ink shadow, set with three inline custom properties.

--sds-shadow-rgb takes bare color channels, so the gradient can fade the same color to true transparent.

--sds-shadow-alpha sets how heavy the shadow reads.

--sds-shadow-size sets the height of each shadow strip.

Set them on one scroller, or on any ancestor to retheme a whole section.

Scroll to the end and this stronger shadow melts away all the same.
