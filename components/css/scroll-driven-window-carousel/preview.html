Three moves, zero scripts

The whole effect is a crop, a keyframe, and a timeline. The browser does the math on the compositor.

1

The window

Each frame is portrait and clips its content. The art is landscape, so object-fit: cover leaves extra width hiding outside the frame.

2

The pan

A keyframe animation slides object-position from 100% to 0%, and view(x) makes the slide's journey across the scrollport drive its progress.

3

The guardrails

An @supports wrap plus a reduced-motion query mean other browsers get the same carousel, just without the pan.

The whole trick

Three declarations carry the effect. The timeline tracks each image across the horizontal scrollport of the strip.

@keyframes wpc-pan {
  from { object-position: 100% 50%; }
  to   { object-position: 0% 50%; }
}

.wpc-slide > img {
  animation: wpc-pan linear both;
  animation-timeline: view(x);
}
