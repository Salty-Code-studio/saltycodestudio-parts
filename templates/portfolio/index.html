/ About

Half designer, half engineer — fully obsessed with the details.

I started out building marketing sites in a coastal studio and never lost the urge to ship the thing myself. Today I sit between design and code, which means handoffs don't get lost in translation — the polish you approve is the polish that ships.

I care most about the quiet stuff: the loading state that doesn't jump, the empty screen that still feels warm, the micro-interaction you only notice when it's missing.

Read my full story →

Research-led, not pixel-first

Every flow starts with the problem and the person, never the trend. Pretty comes after useful.

Systems over screens

I build tokens, components and docs so the work scales after I'm gone. No orphaned Figma files.

Designs that ship

I prototype in real code when it matters, so timing and feel are right before a single ticket is written.

Momentum, not meetings

Tight loops, async updates, things in your hands every few days. I'd rather show than schedule.
